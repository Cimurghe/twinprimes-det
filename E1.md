# E1: twin-prime parity as the root number of an elliptic curve

Status: research notes, 24 November 2026. Not peer reviewed. Author: Roy Sulaiman (with AI assistance; see README).
Every numerical claim is reproduced by `verify_e1.py`.

## 1. The identity

For an odd integer n with n(n+2) squarefree, let

  E_n : y² = x(x − n)(x + 2).

Its odd bad primes are exactly the primes dividing n(n+2), all multiplicative. At l | n the node is split iff (2/l) = 1;
at q | n+2 it is split iff (−2/q) = 1. The local signs give

  W(E_n) = c(n mod 8) · λ(n) λ(n+2),   c = −1 for n ≡ 1, 3 (mod 8),  c = +1 for n ≡ 5, 7 (mod 8),

where λ is the Liouville function. Checked on all 6,452 odd n ≤ 20,001 with n(n+2) squarefree (PARI `ellrootno`), 0 exceptions.
By the 2-parity theorem (Monsky; Dokchitser–Dokchitser), W(E_n) = (−1)^{corank Sel_{2^∞}(E_n)}.
So the parity sign λ(n)λ(n+2) that blocks sieve methods (Selberg's parity problem) is the rank parity of an explicit modular elliptic curve.

## 2. Why this is a candidate engine

Selberg's fake weight w(n) = 1 − λ(n)λ(n+2) satisfies every sieve axiom yet removes all twin pairs. On its support W(E_n) is
forced to the "wrong" sign: for n ≡ 5 (mod 8) every surviving curve has L(E_n, 1) = 0. Measured on 1,352 curves (n ≡ 5 mod 8,
n ≤ 16,717): the fraction with L(E_n, 1) ≠ 0 is 0.46–0.52 and flat as n(n+2) is made rougher (least prime factor ≥ n^δ, δ ≤ 0.35);
in the fake it is 0. Among W = +1 curves the share of analytic rank 0 rises from 0.90 to 0.98 with roughness.

With the pointwise 2-converse for curves with rational 2-torsion (OpenAI, Sept/Oct 2026: Selmer corank ≤ 1 ⇒ analytic rank =
Selmer corank), L(E_n, 1) ≠ 0 ⇔ s₂(E_n) = 0 holds curve by curve, unconditionally.

## 3. Exact restatement on Chen primes

For p ≡ 5 (mod 8) prime with p + 2 squarefree and Ω(p+2) ≤ 2: the 2-Selmer group of E_p is minimal (dimension 2, torsion only)
if and only if p + 2 is prime. (⇐ Qiu–Zhang for twin inputs; ⇒ minimal Selmer gives corank 0, so W = +1, so λ(p+2) = −1, so
p + 2 is prime.) PARI's 2-descent rank bound: 0 for 36/36 twin cases, 1 for 73/73 semiprime cases, p < 6000.
So twin primes in this class are equivalent to infinitely many minimal 2-Selmer groups on a Chen sample.

## 4. The function-field version (the Sawin–Shusterman analogue)

Over F_q[t] (q odd), for f monic of degree n with f(f+2) squarefree and E_f : y² = x(x − f)(x + 2) over F_q(t): a constant c is a
square at a place v iff χ(c) = 1 or deg v is even, so the local signs collapse to

  W(E_f) = ε(n, q) · μ(f) μ(f+2),

with ε depending only on n, q and the place at infinity. With Pellet's formula μ(f) = (−1)^n χ(disc f), the root number of the
family IS the Pellet character, and averaging it is the Sawin–Shusterman twin-Chowla problem. Numerically (all monic f, q = 3 to
n = 11, q = 5 to n = 8, q = 7 to n = 6): Σ μ(f)μ(f+1) / qⁿ ≤ 0.011 in absolute value, while the same sum under the parity-fake
weight is −0.42, −0.65, −0.74. The missing piece over Z is a bound for Σ W(E_n) over rough (or Chen) n.
(The function-field root-number identity is a derivation, not yet checked numerically against L-function signs.)

## 5. Prior art

The curve is classical for twin inputs: Qiu–Zhang (arXiv:math/0103243; 2-Selmer groups), Hatley (arXiv:0909.1614; ranks),
Joshi (arXiv:2508.12340; root-number formula for twin pairs, noting the twin hypothesis cannot be relaxed), arXiv:2610.09370
(Oct 2026; BSD for these curves from the OpenAI low-corank release). All of these assume p, p + 2 prime and study the curve.
E1 runs the other way: the whole family over composite n, with W(E_n) used as a detector of the parity sign λ(n)λ(n+2).
We did not find this use in print.
